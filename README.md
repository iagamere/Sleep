# 🛡️ حارس التركيز (Hares Focus)

تطبيق أندرويد يساعدك على التحرر من إدمان الهاتف، ويحمي نفسه منك في لحظات الضعف.

## الميزات
- **حد الجلسة:** بعد 30 دقيقة استخدام متواصل (قابلة للتعديل) يُقفل الهاتف 10 دقائق استراحة.
- **حظر الليل:** من 00:00 إلى 06:00 المسموح **60 دقيقة فقط طوال الليل**، وبعدها قفل حتى الصباح.
- **وضع التركيز:** قفل لمدة 30د/1س/2س/4س لا يمكن إلغاؤه.
- **حدود يومية لتطبيقات محددة** (مثل إنستغرام 30 د/يوم).
- **تطبيقات أساسية** مسموحة دائماً (الخرائط، البنك...). المكالمات والساعة والشاشة الرئيسية مسموحة دائماً.
- **تنبيه قبل انتهاء الوقت** (5 دقائق ودقيقة).
- **إحصائيات 7 أيام.**

## الحماية من نفسك
| محاولة | ما يحدث |
|---|---|
| تغيير ساعة الهاتف | الحساب يعتمد على عداد داخلي لا يتأثر بالساعة، وشاشة التاريخ والوقت محجوبة، وتعطيل "الوقت التلقائي" يقفل الهاتف |
| تغيير المنطقة الزمنية | تُثبَّت عند أول تشغيل، والشاشة محجوبة |
| حذف التطبيق | صلاحية "مدير الجهاز" + حجب شاشات الإعدادات/التثبيت التي تحمل اسم التطبيق |
| تعطيل خدمة الحماية | الشاشة تُحجب، وإن عُطّلت تظهر شاشة تمنع استعمال الهاتف حتى تُفعَّل |
| إيقاف إجباري / مسح البيانات | شاشات محجوبة أيضاً |
| زيادة الحدود في لحظة ضعف | التخفيف يُؤجَّل 24 ساعة (التشديد فوري) |
| فتح الحماية | كلمة سر عند **شخص موثوق** أو انتظار 24 ساعة، ثم نافذة 15 دقيقة فقط |

## البناء على GitHub (بدون Android Studio)
1. أنشئ مستودعاً جديداً على GitHub وارفع **كل محتويات هذا المجلد** (بما فيها المجلد المخفي `.github` والملف `app/hares.keystore`).
2. افتح تبويب **Actions** ← سيعمل "Build APK" تلقائياً (أو شغّله يدوياً Run workflow).
3. بعد دقائق افتح التشغيل الناجح ← **Artifacts** ← حمّل `HaresFocus-apk` ← فك الضغط ← `app-debug.apk`.
4. ثبّته على الهاتف (اسمح بالتثبيت من مصدر غير معروف).

## الإعداد على الهاتف
1. افتح التطبيق وفعّل كل بند في قائمة الإعداد (إمكانية الوصول، الظهور فوق التطبيقات، مدير الجهاز، البطارية، الإشعارات).
2. أندرويد 13+: إن كان خيار إمكانية الوصول رمادياً: معلومات التطبيق ← ⋮ ← **السماح بالإعدادات المقيدة**.
3. اضبط الإعدادات والتطبيقات، **وجرّب التطبيق يوماً قبل التفعيل الكامل**.
4. عيّن **كلمة سر الشخص الموثوق** (سلّمه الهاتف ليكتبها دون أن تراها).
5. اضغط **تفعيل الحماية الكاملة**.

## تحديث التطبيق لاحقاً
التوقيع ثابت (`hares.keystore`) فيمكن تثبيت نسخة أحدث فوق القديمة. لكن مع تفعيل الحماية تُحجب شاشة التثبيت، فافتح نافذة البوابة (كلمة السر أو 24 ساعة) ثم ثبّت.

## حدود صريحة (لا يوجد حل سحري)
- **الوضع الآمن (Safe mode)** وإعادة ضبط المصنع وأوامر ADB لا يستطيع أي تطبيق منعها. اترك خيار "خيارات المطور / USB debugging" مطفأ.
- يمكنك استعمال جهاز آخر أو متصفح على حاسوب؛ التطبيق يحمي هاتفك فقط.
- أثناء الحماية تُحجب شاشات الإعدادات التي يظهر فيها اسم "حارس التركيز" (مثل قائمة التطبيقات الكاملة). إن احتجتها فافتح النافذة.
- لم يُختبر البناء على جهاز حقيقي بعد؛ إن فشل البناء أو ظهر خطأ أرسل لي النص.
- مفتاح التوقيع علني في المستودع (للاستعمال الشخصي فقط)، فاجعل المستودع **خاصاً**.
